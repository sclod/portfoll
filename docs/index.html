Операційний шар обмінного крипто-сервісу: котирування, життєвий цикл замовлень, кабінети клієнтів, чат підтримки й консоль оператора.

Результат

Завершена демо-версія з вигаданим брендом і чистою історією Git — без даних клієнтів і конфігурації продакшену. Розрахунки в блокчейні свідомо за рамками: це питання ліцензії та провайдера ліквідності, а не коду.

Що зроблено

  • Калькулятор обміну з живими котируваннями та розбивкою комісій
  • Сторінка замовлення зі статусами від очікування до завершення, адресою депозиту та QR-кодом
  • Правила ціноутворення: ручні курси для пар і активів, націнка до ринку, ліміти, імпорт і експорт у JSON
  • Консоль оператора: замовлення, клієнти, каталог активів
  • Чат підтримки в реальному часі на Socket.IO: вкладення, статус «прочитано», призначення оператора, експорт розмови
  • Кабінет клієнта: профіль, історія замовлень, збережені адреси; вхід за паролем або кодом з пошти
